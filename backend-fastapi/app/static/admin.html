Comenzi

O comandă este o listă finalizată pe server. Un document este câte un distribuitor din acea listă, adică un PDF. PDF-urile de inventar și retrimiterile nu se numără, iar mutarea unui produs la alt distribuitor schimbă numărul de documente.
